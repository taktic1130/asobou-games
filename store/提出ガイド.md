## 手順

### 1. 開発者アカウントを作る（ご自身で）
1. https://developer.amazon.com/ja/ を開き、Fireタブレットで使っているのと**同じAmazonアカウント**でサインインします。
2. 開発者情報（氏名・住所・電話番号など）を入力し、利用規約に同意します。
   - 「開発者名」は、一般公開した場合にストアに表示されます。限定テスト配信だけなら一般の人には見えませんが、本名を出したくない場合はニックネームなどにしてください。
3. 無料アプリだけなので、支払い情報（口座）・税務情報の入力は後回しにできる場合があります。求められたら教えてください。

### 2. 新しいアプリを作る
「アプリとサービス」→「新しいアプリを追加」→「Android」を選び、以下を入力します。

| 項目 | 入力する内容 |
|---|---|
| アプリのタイトル | あそぼう |
| アプリのカテゴリー | ゲーム ＞ キッズ（なければ「キッズ」に近いもの） |
| カスタマーサポートの連絡先 | メールアドレス（ストアに表示される場合があります。普段使いでないものがおすすめ）／ Webサイトに `https://github.com/taktic1130/asobou-games` |

### 3. 配信国と価格
| 項目 | 内容 |
|---|---|
| 配信国 | 日本のみ |
| 価格 | 無料 |
| アプリ内課金 | なし |

### 4. アプリの説明（コピーして使ってください）

**短い説明**
```
しんかんせん・おりょうり・ふみきりの 3つのゲームが あそべる、小さなこども向けアプリです。タッチするだけで あそべます。
```

**詳しい説明**
```
「あそぼう」は、3歳ごろのこどもが タッチだけで あそべる やさしいゲームアプリです。字が読めなくても、声と絵で あんないします。

■ しんかんせん
「しゅっぱつ！」を おすと ピンクの しんかんせんが はしります。そらに うかぶ いちごや ほしを タッチして あつめよう。えきに つくと どうぶつの おともだちが のってきます。

■ おりょうり
どうぶつの おきゃくさんが カレーや ケーキを ちゅうもん。ざいりょうを おなべに いれて、まぜまぜ したら できあがり！「おいしい！」と よろこんでくれます。

■ ふみきり
でんしゃを えらぶと「カンカン」と ふみきりが しまって、いろいろな でんしゃが とおります。

・まけたり、ゲームオーバーに なったりしません
・広告、アプリ内課金はありません
・インターネットに つながなくても あそべます
・個人情報を あつめません
```

**特徴（箇条書き欄がある場合）**
```
タッチだけで あそべる 3つのゲーム
広告・アプリ内課金なし
オフラインで あそべる
```

**キーワード**
```
こども, キッズ, 幼児, 新幹線, 電車, 踏切, 料理, おままごと, 知育
```

### 6. コンテンツのレーティング（質問に答える画面）
すべての項目で「なし」になるはずです。
- 暴力・性的表現・ギャンブル・アルコール・薬物・下品な言葉：**なし**
- 位置情報の取得・個人情報の収集・ユーザー同士の交流：**なし**
- 広告：**なし**
- **こども向けのアプリですか（13歳未満向け）**：**はい**
- プライバシーポリシーURL：`https://taktic1130.github.io/asobou-games/privacy.html`

### 7. APKのアップロード
1. 「ファイル」（App Files）で `dist/asobou.apk` をアップロードします。
2. 対応端末は Fireタブレットを中心に、自動判定のままでOKです（Fire TV は外してください）。
3. 「Amazon DRM を適用しますか」→ **いいえ**
4. 「Fire以外の端末に配信」などは **いいえ** でOKです。

### 8. 限定テスト配信（Live App Testing）を作る
1. アプリのページで「Live App Testing」（ライブアプリテスト）を開き、「新しいテスト」を作ります。
2. テスター（試す人）に、**Fireタブレットで使っているAmazonアカウントのメールアドレス**を登録します。
3. 内容を確認して「テストを提出」を押します（**ここはご自身で押してください**）。
4. Amazon側の確認が終わると（数時間〜1日程度のことが多いようです）、登録したメールに招待が届きます。

### 9. タブレットに入れる
1. 先に、USBで入れた「あそぼう」をアンインストールします（同じアプリなので、残っているとストア版が入らないことがあります）。
2. タブレットで招待メールのリンクを開くか、アプリストアで「あそぼう」を探してインストールします。
3. 「設定」→「プロフィールとファミリーライブラリ」→ 娘さん →「コンテンツを追加」→「Amazonで購入したもの」の中に「あそぼう」が出るか確認し、チェックを入れます。

---

## 注意
- アプリを直したときは、APKを作り直して（`bash android/build.sh`、バージョン番号を1つ上げる）、同じテストに新しいAPKを追加します。
- 限定テスト配信には期限（90日程度）がある場合があります。期限が近づいたら延長か作り直しが必要です。
